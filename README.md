# Employee Success Modal

A reusable React modal component built with Material UI.

This component displays a confirmation dialog after an employee has been successfully created in the HRNet application.

## Features

* Material UI styling
* Configurable open/close state
* Custom callback for confirmation actions
* Reusable across multiple applications

## Installation

npm install @elenixu/employee-success-modal


## Props

| Prop      | Type     | Description                                         |
| --------- | -------- | --------------------------------------------------- |
| open      | boolean  | Controls whether the modal is visible               |
| onClose   | function | Called when the modal is closed                     |
| onConfirm | function | Called when the user clicks the confirmation button |


## Technologies
